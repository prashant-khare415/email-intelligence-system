# 📧 Email Intelligence System
A command-line Python application that analyzes email addresses using **Python string operations**. This project extracts useful information such as the username, domain, extension, and validates basic email details using conditional statements.

## 🚀 Features
- Extract Username
- Extract Domain Name
- Identify Email Extension
- Display Username Length
- Find Position of '@'
- Reverse Email Address
- Basic Username Validation
- Basic Domain Validation
- Clean and Structured Report

## 🛠️ Technologies Used
- Python 3
- String Methods
- Conditional Statements (`if`, `elif`, `else`)

## ▶️ How to Run
1. Clone this repository.
2. Run the Python file.

```bash
Email_Analyzer_System.py
```

## 🎯 Concepts Practiced
- String Indexing & Slicing
- split()
- find()
- isalnum()
- isalpha()
- isdigit()
- islower()
- len()
- String Validation
- Nested if Statements
